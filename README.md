# Mint Menu Studio

**Локальный графический редактор меню Linux Mint Cinnamon.** Переносите приложения и целые разделы мышью, создавайте ярлыки, редактируйте команды запуска, скрывайте пункты, настраивайте избранное и отменяйте изменения даже после перезапуска редактора.

Приложение работает в вашей пользовательской сессии, без сервера, учётной записи и прав администратора.

> **Важное различие:** сортировка строк в редакторе работает без дополнительных компонентов, но стандартный апплет Cinnamon принудительно сортирует их по алфавиту. Чтобы выбранный порядок отображался и в самом меню Cinnamon, **по желанию** установите отдельную пользовательскую надстройку. Она не устанавливается по умолчанию.

## Возможности

- **Перетаскивание приложений:** перемещение между разделами и сортировка внутри раздела, включая групповое выделение Ctrl / Shift.
- **Перетаскивание разделов:** ручное расположение категорий меню.
- **Папки/теги с галочками:** правый щелчок по приложению → «Разделы приложения» → отметьте все нужные разделы, снимите ненужные. Приложение может одновременно находиться в нескольких папках.
- **Новые пункты:** пользовательские разделы и ярлыки с названием, описанием, иконкой и командой запуска.
- **Свойства:** правка существующих ярлыков без потери посторонних полей файла .desktop.
- **Скрытие вместо удаления:** приложение остаётся установленным, его можно вернуть из списка скрытых.
- **Избранное:** добавление, исключение и перестановка значков в левом столбце Cinnamon.
- **Отмена и повтор:** Ctrl+Z, Ctrl+Shift+Z или Ctrl+Y; история сохраняется между сеансами.
- **Поиск:** названия, описания и команды запуска.

Порядок программ можно задавать независимо для каждого раздела и отдельно для «Всех приложений». Результаты поиска остаются отсортированными по релевантности/алфавиту, а специальные строки самого редактора не перемещаются.

## Установка

Проверенная среда: **Linux Mint 22.3 / Cinnamon 6.6.9**, Python 3.12, GTK 3, CMenu 3. Нужны предустановленные системные модули Python GI и Cinnamon CMenu; обычно они уже присутствуют в Linux Mint Cinnamon. Другие версии требуют проверки.

Скопируйте или клонируйте репозиторий, затем запустите установщик **обычным пользователем, без sudo**:

~~~bash
git clone https://github.com/aaamosh/mint-menu-studio.git
cd mint-menu-studio
/usr/bin/python3 install.py
~~~

Редактор появится в меню приложений под именем **«Редактор меню»** (в русской локали) или **«Mint Menu Studio»**. Из терминала:

~~~bash
/usr/bin/python3 ~/.local/share/mint-menu-studio/app.py
~~~

**Обычная установка не изменяет стандартный апплет Cinnamon.** Функции управления ярлыками, разделами и избранным работают сразу. Перетаскиванием можно сохранять свой порядок в редакторе, но реальное меню без надстройки по-прежнему сортирует пункты самостоятельно.

## Необязательная надстройка порядка

Если необходимо, чтобы Cinnamon отображал именно ваш порядок разделов и значков:

~~~bash
/usr/bin/python3 install.py --with-order-applet
cinnamon-dbus-command ReloadXlet menu@cinnamon.org APPLET
~~~

Надстройка представляет собой **пользовательскую копию стандартного апплета меню**, созданную из файлов установленной версии Cinnamon с небольшими изменениями сортировки. Она считывает порядок из файла **~/.config/mint-menu-studio/order.json** и отслеживает его изменения. Исходные файлы системы в **/usr/share/cinnamon** не изменяются, остальные апплеты и панели не затрагиваются.

Риски и ограничения: после обновления Cinnamon пользовательская копия может устареть; повторите команду с **--with-order-applet**, чтобы пересобрать её из новой версии. Установщик не перезаписывает стороннюю пользовательскую копию меню и отказывает при несовместимости. Надстройка разработана и проверена для указанной версии Cinnamon, а не для всех будущих выпусков.

Чтобы **отключить** надстройку, сохранив редактор и параметры порядка:

~~~bash
/usr/bin/python3 install.py --remove-order-applet
cinnamon-dbus-command ReloadXlet menu@cinnamon.org APPLET
~~~

После отключения применяется обычная сортировка Cinnamon. [Подробности и восстановление](docs/TROUBLESHOOTING.md).

## Как пользоваться

1. Выберите раздел в левой колонке. Чтобы изменить расположение разделов, **перетащите один выше или ниже другого**.
2. Для сортировки приложений внутри раздела **перетащите значок выше или ниже** в правом списке. Выделение Ctrl / Shift позволяет передвинуть несколько пунктов разом.
3. Чтобы сменить раздел приложения, **перетащите его на раздел слева** либо воспользуйтесь кнопкой «Переместить». При переносе из конкретного раздела удаляется только членство в нём; из «Всех приложений» или поиска назначается целевой раздел вместо текущих.
4. **Правая кнопка на значке → «Разделы приложения»** раскрывает боковое подменю со всеми папками и галочками. Изменение каждой галочки применяется немедленно. Повторно откройте подменю, чтобы изменить следующую; снятие последней галочки может убрать пункт из меню, но не удаляет программу.
5. Кнопки «Раздел» и «Приложение» создают новые пункты. Двойной щелчок открывает свойства, кнопка «Убрать» скрывает, а раздел «Скрытые приложения» возвращает.
6. Для левой панели избранного перетащите приложение в «Избранное», затем переставьте его мышью или стрелками.

Изменения сохраняются сразу. В отличие от удаления программы через пакетный менеджер, «Убрать» скрывает только пункт в меню. Новые пустые разделы видны в редакторе, но стандартное меню показывает их после добавления хотя бы одного приложения.

## Данные и отмена изменений

- Настройки разделов: пользовательские XDG-каталоги **~/.config/menus**, **~/.local/share/applications** и **~/.local/share/desktop-directories**.
- Пользовательский порядок: **~/.config/mint-menu-studio/order.json**.
- История и восстановление: **~/.local/state/mint-menu-studio**.
- Сам редактор: **~/.local/share/mint-menu-studio**.
- Необязательная надстройка: **~/.local/share/cinnamon/applets/menu@cinnamon.org**.

Если файл изменился за пределами редактора, конфликтная операция или отмена не перезаписывает чужие изменения. Существующие .desktop-команды не выполняются редактором.

## Удаление

~~~bash
/usr/bin/python3 ~/.local/share/mint-menu-studio/install.py --uninstall
~~~

Установщик удаляет собственные файлы и собственную надстройку (если включена), но **оставляет ваши настройки меню и историю**. После удаления надстройки может потребоваться перезагрузка только апплета командой выше.
