# Contributing / Участие

Спасибо за интерес к Mint Menu Studio.

1. Воспроизводите ошибку на тестовом профиле Cinnamon, не перезаписывая рабочую конфигурацию.
2. Создавайте небольшие изменения с проверками и обновлённой документацией.
3. Уточняйте версию Linux Mint, Cinnamon, Python и GTK в сообщениях об ошибке.
4. Не прикладывайте в задачи файлы настроек со своих компьютеров без очистки личных путей, названий, команд, токенов или других приватных данных.
5. Изменения генератора опционального апплета проверяйте по исходникам поддерживаемой версии Cinnamon; не изменяйте системные файлы пользователя.

**Базовая команда проверок (в Linux Mint Cinnamon):**

~~~bash
/usr/bin/python3 -m unittest discover -s tests -v
/usr/bin/python3 -m py_compile app.py menu_backend.py menu_bridge.py install.py
~~~

Графическое перетаскивание проверяется дополнительно в Xvfb либо реальной пользовательской сессии. Не публикуйте чужой код Cinnamon под лицензией MIT: созданная пользовательская копия апплета наследует требования лицензии исходного кода.

Issues and pull requests are welcome. Please include a concise reproduction and expected behavior.
