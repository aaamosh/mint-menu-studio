# Проверка реализации

Все операции с действующим меню следует проверять без изменения настоящего профиля пользователя.

## Минимальные проверки исходников

~~~bash
/usr/bin/python3 -m py_compile app.py menu_backend.py menu_bridge.py install.py
/usr/bin/python3 -m unittest discover -s tests -v
~~~

Тесты используют временные XDG_CONFIG_HOME / XDG_DATA_HOME / XDG_STATE_HOME и GSETTINGS_BACKEND=memory. Запускать их надо обычным пользователем на Linux Mint Cinnamon с Python GI/CMenu. При отсутствии CMenu Cinnamon-зависимые интеграционные сценарии пропускаются.

Для отдельного GUI-smoke с реальными Gtk.CheckMenuItem и CMenu:

~~~bash
xvfb-run -a dbus-run-session -- /usr/bin/python3 tests/gui_category_submenu_smoke.py
~~~

## Изолированная проверка GUI

Для интерактивного теста подходит отдельный Xvfb-дисплей; задайте временные XDG каталоги и DBus user session перед запуском app.py. Проверьте:
- перенос одного и группы приложений между разделами;
- контекстное подменю «Разделы приложения», наличие всех галочек и установленных назначений;
- добавление второй категории, снятие только одной, снятие последней и восстановление Ctrl+Z;
- конфликт внешнего изменения .menu файла при попытке изменить галочку;
- перестановку строки до и после соседней строки;
- перестановку разделов;
- создание, скрытие и восстановление ярлыка/раздела;
- Ctrl+Z / Ctrl+Shift+Z и повторное открытие редактора;
- конфликты от внешней правки файла;
- отсутствие изменений исходных системных .desktop файлов.

## Необязательный адаптер

- Пустая стандартная установка не создаёт пользовательский апплет.
- При --with-order-applet каталог апплета создаётся в пользовательском XDG_DATA_HOME.
- При --remove-order-applet удаляются только собственные проверенные файлы; order.json сохраняется.
- Несовместимая версия Cinnamon и чужой апплет не должны перезаписываться.
- Сгенерированные applet.js / appUtils.js должны проходить синтаксическую проверку в установленном CJS.

В живом сеансе Cinnamon проверяйте загрузку пользовательского апплета по логам и что перемещения действительно отображаются в меню, а не только в редакторе.

## Известная зона совместимости

Базовая разработка и GUI-проверка выполнены на Linux Mint 22.3, Cinnamon 6.6.9. Проверка на иных версиях Cinnamon и иных дистрибутивах не объявляется завершённой.
